A neural net you can read

The layout below is computed by a neural network: every tile's size and position comes out of 6,693 neurons in 201 layers. Nobody trained it. Every weight was written by hand with handwired, so every neuron has a known job. Breed the layout first, then take the network apart and check each interpretability method against the answer key.

    Breed it

    Each layout is a genome: 45 numbers the network reads, like how wide a tile wants to be, which order tiles come in, and the narrowest a tile may get. Pick one or two you like and breed. Children are mutated copies; with two parents, each tile's genes come from one parent or the other. Each round tries 256 children, throws out the ones the network marks invalid, and shows the ones your taste model ranks highest, plus two at random.

    Look inside

    Interpretability means working out what a network's parts do. With a trained model you never learn whether you got it right. Here every neuron was written by a person, so each method below can be graded. All five run on your current main layout.

    1. Read a neuron

    Search the network by name. In a trained model there are no names, and finding them is most of the work. Here the builder tagged 804 neurons as it created them, and every other neuron takes the name of the one it feeds.

      Look at the network's shape. Wide layers on the left sort and size the tiles all at once. Then comes a long, thin neck: the row-breaking loop, which has to place one tile before it can place the next, unrolled into 100 layers of depth. A sequential algorithm became depth.

      2. Seams are neurons flipping

      Every neuron here is a weighted sum, a ReLU, a ReGLU (a value times a ReLU), or a 0-or-1 decision. Inside a region of inputs where no ReLU switches and no decision flips, the whole network is one fixed smooth formula. It can only change behavior where some neuron crosses its threshold. The polytope lens studies ReLU networks this way. Every line in the atlas is one of those crossings. Below are the main layout's seams from 360 to 1920 px, with the exact width and the neurons that flip there.

        Click a seam to plot the score its row-break neuron rounds. At 0.5 or above, the tile starts a new row.

        3. Break it: knocking out vs. gradients

        Two ways to ask "does this neuron matter?" Knock it out and measure how far the tiles move, or take the gradient of the layout with respect to it (gradient times activation, what a saliency map shows). Each dot is one neuron. Accent dots sit behind a decision: every path from them to a tile crosses a 0-or-1 step, so their gradient is exactly zero, whatever the input.

        This is why saliency maps mislead. A gradient only sees the local linear region. It cannot see what happens across a decision boundary, which is where this network does most of its work.

        4. Patch it

        Activation patching asks where a difference lives. Run layout A, but copy one neuron's value from run B and see how much of B shows up. Here B is A with one gene changed, so you know the answer before you start: the change has to enter through the neurons that read that gene.

        +50%

        1.0 means copying that single neuron turns A into B. Change the minimum tile width and one neuron, the first to read it, carries the whole difference. Change tile 1's importance and a chain of neurons each carry part of it, because the value is copied from link to link. "Where does it live?" then has several right answers. This is the same problem as backup heads in language-model circuits. The curve below patches whole layers: early layers carry everything because, in this network, every later layer reads from them directly.

        5. Probe it: readable isn't used

        A probe is a small linear model trained to read a fact out of one layer's neurons. High probe accuracy is often taken to mean the network uses that fact there. Train a probe at every layer on 1,200 variations of your main layout at random widths, then erase what the probe found and see whether the layout changes.

        Click a bar to erase that layer's probe direction (the amnesic probing test). Where the network uses a fact, erasing it scatters the tiles. In layers that only feed the validity checks, the fact can still be read perfectly, yet erasing it moves nothing. Readable doesn't mean used. See also control tasks.

        What a trained network won't give you

        This network is clean in ways real ones aren't. Each neuron has one job, it is sparse, and nothing is stored in superposition. So the point isn't that real models look like this. It's that each method above was graded against the truth, and three of them have a failure mode you could see: gradients go blind at decisions, patching smears across copies, and probes read facts the network has stopped using. Tracr and InterpBench build compiled and semi-synthetic transformers with known circuits for the same reason.
